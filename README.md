# Laravel Server Manager

اسکریپت Shell جامع برای پیکربندی، استقرار، امن‌سازی و نگهداری سرورهای خام اوبونتو جهت میزبانی پروژه‌های PHP و Laravel.

## قابلیت‌ها

- **نصب پشته LEMP**: راه‌اندازی Nginx، MySQL و PHP با افزونه‌های مورد نیاز Laravel.
- **ابزارهای توسعه**: نصب خودکار Node.js، npm، Composer و Git.
- **سرویس‌های پس‌زمینه**: پیکربندی Redis و Supervisor برای مدیریت صف‌ها.
- **امنیت**: پیکربندی فایروال (UFW)، نصب Fail2ban و ایمن‌سازی سرویس SSH.
- **بهینه‌سازی**: تنظیمات اولیه برای عملکرد بهتر وب‌سرور و پایگاه داده.

## پیش‌نیازها

- سیستم‌عامل: Ubuntu 20.04 / 22.04 / 24.04
- دسترسی کاربر: `root` یا کاربری با دسترسی `sudo`

## نصب و استفاده

۱. مخزن را دریافت کنید:
```bash
git clone https://github.com/yourusername/laravel-server-manager.git
cd laravel-server-manager

۲. دسترسی اجرایی به اسکریپت بدهید:
bash
chmod +x setup.sh

۳. اسکریپت را اجرا کنید:
bash
sudo ./setup.sh

## ساختار فایل‌ها

- `setup.sh`: فایل اجرایی اصلی اسکریپت.
- `configs/`: شامل فایل‌های پیکربندی پیش‌فرض برای Nginx، PHP و Supervisor.
- `logs/`: مسیر ذخیره‌سازی لاگ‌های مربوط به فرآیند نصب.

## نگهداری

برای به‌روزرسانی پکیج‌ها و سرویس‌ها در آینده، اسکریپت شامل توابع نگهداری داخلی است. به مستندات داخل کد مراجعه کنید.
